Einrichten: fünf BefehleSetting up: five commands

Der Start-Abschnitt der README ist die Vorlage. Eine virtuelle Umgebung (venv) ist ein Ordner mit eigenem Python und eigenen Paketen; sie hält das Projekt von der Systeminstallation getrennt. Ohne sie verweigert pip auf dem Mac die Installation mit externally-managed-environment (PEP 668) – das ist Absicht, kein Fehler. Aktivieren setzt nur den Pfad; deshalb muss es in jedem neuen Terminalfenster wiederholt werden. The README's start section is the template. A virtual environment (venv) is a folder with its own Python and its own packages; it keeps the project separate from the system installation. Without it pip on the Mac refuses installation with externally-managed-environment (PEP 668) – that is intentional, not a bug. Activating only sets the path; hence it has to be repeated in every new terminal window.

LM Studio: Modell, Server, Modell-IDLM Studio: model, server, model ID

In LM Studio ein Chatmodell laden, das zur Hardware passt – das Fallbeispiel lief mit gemma-4-12b-it-mlx in 6bit-Quantisierung auf einem Mac mit Apple Silicon. Dann den lokalen Server starten (Developer-Ansicht, „Start Server“, oder lms server start; Port 1234). Der Server bietet eine OpenAI-kompatible API; /v1/models listet die geladenen Modelle mit ihren IDs. Diese ID gehört in die Profildatei: profiles/local/.env.example nach profiles/local/.env kopieren und LOCAL_LLM_MODEL eintragen. Nur bei genau einem geladenen Chatmodell darf die Zeile leer bleiben; die Mac-Prüfung hatte drei, und die Autoauswahl brach mit einer klaren Meldung ab. Load a chat model in LM Studio that fits the hardware – the case study ran with gemma-4-12b-it-mlx in 6bit quantisation on a Mac with Apple Silicon. Then start the local server (developer view, “Start Server”, or lms server start; port 1234). The server offers an OpenAI-compatible API; /v1/models lists the loaded models with their IDs. That ID belongs in the profile file: copy profiles/local/.env.example to profiles/local/.env and enter LOCAL_LLM_MODEL. Die Phasen: wie das Fallbeispiel entstandThe phases: how the case study came about

Die Historie hat 35 Commits, von 538ad35 am 07.07.2026 bis faa573f am 20.09.2026; git log im geklonten Ordner zeigt sie. Zehn davon sind die Phasen; der letzte Commit ist der PageIndex-Umbau aus Lab 08. Die Baseline war ein RAG ohne Präfixe, ohne Reranker und ohne Messung. Phase 0 brachte die Präfixe, den persistenten Index mit Fingerprint und den Messlauf; Phase 1 den Reranker, Phase 1+ das zeilenweise Tabellen-Chunking und den Fehlercode-Hybrid. Das Design-Dokument vom 07.07.2026 hält die Messung dazu fest: Recall 64 → 96 %, MRR 0,73 → 1,00, Hit@1 70 → 100 % auf den zehn Fragen. Dann Quellen, SSE-Streaming, der Guardrail, PageIndex – und im September die Vereinigung von LM Studio und OpenAI mit Sitzungsschlüsseln sowie der Cache-Fix aus der Mac-Prüfung. The history has 35 commits, from 538ad35 on 7 July 2026 to faa573f on 20 Sept 2026; git log in the cloned folder shows them. Ten of them are the phases; the last commit is the PageIndex rebuild from Lab 08. The baseline was a RAG without prefixes, without reranker and without measurement. Phase 0 brought the prefixes, the persistent index with fingerprint and the evaluation run; phase 1 the reranker, phase 1+ the row-wise table chunking and the error-code hybrid. The design document of 7 July 2026 records the measurement: recall 64 → 96 %, MRR 0.73 → 1.00, hit@1 70 → 100 % on the ten questions. Then sources, SSE streaming, the guardrail, PageIndex – and in September the unification of LM Studio and OpenAI with session keys plus the cache fix from the Mac audit.

Die Lehre der Reihenfolge:The lesson of the order: Zuerst die Messung (Phase 0), dann die Verbesserungen. Ohne den Messlauf wäre der Reranker eine Behauptung geblieben. Und der zentrale Befund zur Antwortzeit stand nicht in der Suche, sondern in der Modellwahl: Ein Reasoning-Modell brauchte rund 250 Sekunden, das Instruct-Modell gemma-4-12b rund 40 – deshalb ist es der Standard. First the measurement (phase 0), then the improvements. Without the evaluation run the reranker would have remained a claim. And the central finding on answer time lay not in retrieval but in model choice: a reasoning model needed about 250 seconds, the instruct model gemma-4-12b about 40 – which is why it is the default.

Ein eigenes DokumentA document of your own

Das Fallbeispiel ist auf ein Handbuch gebaut, aber nur an vier Stellen daran gebunden: die Wissensdatei siemens_wissen.md, die Fehlercode-Regex in rag_engine.py, die vier Verfahrensgruppen in manual_context.py und die zehn Fragen in eval/questions.json. Für ein anderes PDF: mit parser.py extrahieren (optionale Pakete), die Extraktion an Tabellen und Warnhinweisen gegen das PDF prüfen (Lab 03), die Wissensdatei ersetzen – der Fingerprint erzwingt den Neuaufbau (Lab 09) –, eigene Fragen mit Stichwörtern aus dem Dokument anlegen und run_eval.py laufen lassen (Lab 08). Die Verfahrensgruppen sind Handarbeit und gelten nur für dieses Handbuch; ohne sie läuft das System, nur ohne die ausgeweiteten Anleitungen. The case study is built on one manual but bound to it in only four places: the knowledge file siemens_wissen.md, the error-code regex in rag_engine.py, the four procedure groups in manual_context.py and the ten questions in eval/questions.json. For another PDF: extract with parser.py (optional packages), check the extraction at tables and warnings against the PDF (lab 03), replace the knowledge file – the fingerprint forces the rebuild (lab 09) –, create your own questions with keywords from the document and run run_eval.py (lab 08). The procedure groups are handwork and apply only to this manual; without them the system runs, just without the expanded procedures. 

python -m pip install -r requirements-optional.txt
python parser.py --pdf mein-handbuch.pdf --output mein_wissen.md
# erst prüfen, dann die aktive Wissensdatei ersetzen (der Dateiname ist im Code fest):
mv mein_wissen.md siemens_wissen.md
python eval/run_eval.py
